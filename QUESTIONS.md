# QUESTIONS — Interview question bank

Maintained by the mentor (see MENTOR.md section 6). One entry per question; update instead of duplicating. Mark the learner's own questions `(my question)`. The *Short answer* is written only after the learner has answered. *Re-ask after* is counted in lessons (study order), never days: weak = within 2 lessons, ok = after 5, strong = at the module review.

Entry format:

```
### Q<n> — Lesson NN
**Question:** ...
**Short answer:** ...
**Where it appears:** lessons/NN-slug/...
**Rating:** weak | ok | strong
**My question?** yes | no
**Tags:** module / topic
**Last asked:** date (record only)
**Re-ask after:** lesson NN
```

Keep scenarios fictional or sanitised: no employer-confidential information.
